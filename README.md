# MyRoutine

## 🧠 Visão Geral

**MyRoutine** é uma aplicação web desenvolvida em **Angular** para gerenciamento de rotinas e hábitos diários.  
O projeto tem como objetivo consolidar conhecimentos em **TypeScript** e **Angular**, com foco em boas práticas, organização de código e retomada de ritmo após um período sem contato com tecnologia.

Este não é um projeto tutorial, mas sim um projeto de estudo estruturado e evolutivo.

---

## 🚀 Funcionalidades

- Criar, editar e remover rotinas
- Adicionar hábitos a uma rotina
- Marcar hábitos como concluídos
- Visualizar progresso de conclusão
- Navegação entre telas

---

## 🛠️ Tecnologias Utilizadas

- Angular
- TypeScript
- RxJS
- Angular Router
- Reactive Forms
